02 · Task 1

Image Format Comparison

We compare a PNG (lossless) and JPEG (lossy) version of the same group photo. PNG preserves every pixel exactly using deflate compression; JPEG discards subtle color data the human eye barely detects, achieving far smaller file sizes at the cost of compression artifacts.

Technical Analysis — Image Compression

PNG (Portable Network Graphics) uses lossless compression: the DEFLATE algorithm encodes repeating patterns without discarding any pixel data. The decoded image is bit-for-bit identical to the original. This makes PNG ideal for screenshots, diagrams, and images with sharp edges or text, but results in larger files for photographs.

JPEG (Joint Photographic Experts Group) uses lossy compression based on Discrete Cosine Transform (DCT). The image is divided into 8×8 pixel blocks; high-frequency detail within each block is quantized (rounded), and the result is Huffman-encoded. Quality settings (1–100) control how aggressively detail is discarded. Human vision is more sensitive to luminance than chrominance, so JPEG compresses color channels more — this is chroma subsampling (4:2:0 or 4:2:2). At Q=80, file sizes are typically 5–20× smaller than PNG with minimal visible artifacts.

03 · Task 2

Audio Format Comparison

We compare WAV (uncompressed PCM) against MP3 (lossy compressed) using the same IIUM-related audio clip. WAV stores raw samples; MP3 uses psychoacoustic masking to discard sounds humans cannot perceive.

Technical Analysis — Audio Compression

WAV (Waveform Audio File Format) stores raw PCM (Pulse Code Modulation) samples. A standard CD-quality WAV uses a 44,100 Hz sampling rate and 16-bit depth, producing 1,411 kbps of data for stereo audio — approximately 10 MB per minute. Every sample is preserved exactly as recorded.

MP3 (MPEG-1 Audio Layer III) applies psychoacoustic modeling: frequencies masked by louder adjacent frequencies are discarded, inaudible high-frequency content is removed, and the remaining data is Huffman-encoded. At 128 kbps, MP3 achieves roughly 11:1 compression over CD-quality WAV. At 192–320 kbps, quality differences become imperceptible to most listeners.

04 · Task 3

Video Format Comparison

We compare an original (high-quality) video against an MP4/H.264 compressed version. The clip shows our group members engaged in academic activities on IIUM campus.

Technical Analysis — Video Compression

H.264 / AVC (Advanced Video Coding) is a block-based hybrid coding standard. It divides frames into 16×16 macroblocks and uses two core techniques: (1) Intra-frame prediction — compressing a single frame using spatial redundancy (like JPEG), producing an I-frame; (2) Inter-frame prediction — encoding only the difference between frames using motion vectors, producing P-frames and B-frames. A Group of Pictures (GOP) contains one I-frame followed by many P/B-frames, achieving 50:1 to 200:1 compression over raw video.

The MP4 container (.mp4) wraps the H.264 video stream with an AAC audio stream and metadata. It is widely supported across browsers, devices, and platforms.

05 · Summary

Conclusions

This lab demonstrates the fundamental trade-off in multimedia compression: reducing file size always comes at some cost — either in quality (lossy) or computational complexity (lossless). Choosing the right format depends on the application context.

🖼 Image Conclusions

PNG preserves pixel-perfect quality at the cost of larger file sizes. JPEG achieves dramatic size reduction with minimal perceptual loss at moderate quality settings (Q≥75). For photographs shared online, JPEG is the practical choice. For logos and UI assets, PNG is preferred. Write your specific finding here...

🔊 Audio Conclusions

WAV provides a faithful reference but is impractical for streaming or storage. MP3 at 128–192 kbps is indistinguishable from WAV for most listeners in typical listening conditions. 🎥 Video Conclusions

H.264 achieves remarkable compression through inter-frame prediction, making modern video streaming possible. The GOP structure means random seeking requires decoding from the nearest I-frame.
